# Matt's Lair GDevelop 5

> [!abstract] Purpose
> Turn the procedural club mesh into a browser-ready GDevelop 5 3D scene.

## Files

- `MattsLairGDevelop.json` — starter project;
- `assets/` — place `Matts_Lair_Club.glb` here.

## Setup

1. Export the club as GLB.
2. Copy the result into `gdevelop5/assets/Matts_Lair_Club.glb`.
3. Open `MattsLairGDevelop.json` in GDevelop 5.
4. Confirm the 3D model resource points to `assets/Matts_Lair_Club.glb`.
5. Add directional and ambient light effects to the base layer.
6. Preview the project and tune movement/camera events.

GDevelop natively supports GLB; FBX should remain part of the Unity/VRChat workflow.
